Neon Coast Cover Studio — an offline web app that turns your photos and a caption into GTA 6-style cover art: the multi-panel poster look with bold condensed lettering, a Vice City sunset or neon grade, and one-step PNG exports in the common post sizes. Everything runs in the browser from its own files; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ — pick a layout and a grade, drop in your photos, drag to pan, scroll to zoom, and export 1080×1080, 1080×1350 or 1920×1080 PNGs.
